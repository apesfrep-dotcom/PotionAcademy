# Potion Academy: The Potion Shop

Grade 3 liquid volume (mL, L, 1 L = 1,000 mL; Bridges U4 M1 S5, 3.MD.2).

| Page | Who | What |
|---|---|---|
| `index.html` | Teacher | Landing page with links and how to run it |
| `lesson.html` | Teacher, projected | Narrated lesson, stops at each notebook box |
| `lab.html` | Students, Chromebook | 6 potion orders, then the open Potion Creator with a printable recipe card |
| `Potion_Lab_Notebook.pdf` | Teacher, copy first | Student notebook (2 pages) + answer key |

Each page is a single self-contained HTML file (fonts, pictures, and narration audio are embedded), so the site has no build step and no outside dependencies. Student progress is saved in the browser on that Chromebook only. Finishing all six orders unlocks the Potion Creator button.
